## Candidate: Rule-based + optional OpenAI API (with fallback)

### Findings
- OpenAI's current pricing page lists three "cheapest small" text models: **gpt-5-nano** at $0.05/1M input, $0.40/1M output, $0.005/1M cached input; gpt-4.1-nano at $0.10/$0.40 ($0.025 cached); gpt-4o-mini at $0.15/$0.60 ($0.075 cached) — gpt-5-nano is explicitly the lowest-cost option across all current OpenAI models — Source: OpenAI, developers.openai.com/api/docs/pricing, n.d. (live page), accessed 2026-10-28, confidence: high, class: pricing
- Cross-check of gpt-5-nano pricing ($0.05 input / $0.40 output / $0.005 cached per 1M tokens) matches an independent LLM cost calculator — Source: getmaxim.ai Bifrost LLM Cost Calculator, n.d., accessed 2026-10-28, confidence: medium, class: pricing
- Realistic per-call cost estimate for this feature: a short task-classification prompt (~150–300 input tokens: system instructions + task text) plus a short structured JSON output (~50–100 tokens) on gpt-5-nano costs roughly $0.00003–$0.00006 per call — well under a hundredth of a cent; even 1,000 classification calls would cost only a few cents — Source: derived calculation from OpenAI's own published gpt-5-nano rates above, accessed 2026-10-28, confidence: high, class: pricing (derived)
- Latency for gpt-5-nano at "minimal" reasoning effort is ~0.8s time-to-first-token, but at "medium"/"high" reasoning effort (gpt-5-nano is a reasoning-capable model) time-to-first-token balloons to 37–118 seconds — this app must explicitly set low/minimal reasoning effort to keep latency in the sub-2-second range for a short classification task — Source: artificialanalysis.ai, GPT-5 nano (minimal/medium/high) provider benchmarks, n.d., accessed 2026-10-28, confidence: medium, class: latency
- OpenAI's data-usage policy, in effect since March 1, 2023: "data sent to the OpenAI API is not used to train or improve OpenAI models unless you explicitly opt in." Abuse-monitoring logs (containing customer content/metadata) are retained up to 30 days by default; some endpoints (e.g. /v1/conversations, /v1/assistants) persist "until deleted" instead; Zero Data Retention (ZDR) is available for eligible endpoints/customers — Source: OpenAI, developers.openai.com/api/docs/guides/your-data, policy effective 2023-03-01, accessed 2026-10-28, confidence: high, class: privacy policy
- OpenAI has a dedicated blog post on expanding Zero Data Retention ("Offering Zero Data Retention for frontier models") and reportedly rolled out "Private Safety Processing" to API customers in phases starting 2026-09-22 so ZDR customers' content is never seen by OpenAI staff — Source: openai.com/index/offering-zero-data-retention-for-frontier-models/ (title/claim only, not fully fetched), n.d., accessed 2026-10-28, confidence: low (unverified full content), class: privacy policy
- Integration pattern (primary docs): OpenAI recommends the **Responses API** (`/v1/responses`) with a `text.format` JSON-schema parameter (`strict: true`) for structured output ("Structured Outputs"); the older Chat Completions API's `response_format` with `json_schema` also works. Auth is `Authorization: Bearer $OPENAI_API_KEY`. Both Python and JS SDKs offer convenience methods (`client.responses.parse` with a Pydantic/Zod schema) as well as raw REST/cURL — Source: OpenAI, developers.openai.com/api/docs/guides/structured-outputs, n.d., accessed 2026-10-28, confidence: high, class: integration pattern
- OpenAI no longer grants automatic signup trial credits to most new accounts (the old $5–$18 trial was discontinued); as of a reported change on 2026-05-13, OpenAI replaced the legacy free developer tier with a one-time $15 trial credit on a 30-day window; separately, an opt-in "share your API traffic for training" program grants free daily tokens (up to 1M/day on large models, 10M/day on mini/nano models) — Source: perkstack.co "Free OpenAI API Credits 2026: What's Real and What Isn't" and related aggregator blogs, n.d./2026, accessed 2026-10-28, confidence: low-medium (secondary blogs, exact OpenAI-primary confirmation not fetched), class: free tier
- Rate limits scale by paid usage tier (not a free-forever tier): reported tier structure runs from an entry paid tier (~$5 spent) up through higher tiers (~$50/$100/$250/$1,000 cumulative spend), with GPT-4o-class RPM/TPM limits ranging roughly from 500 RPM/30K TPM at the lowest paid tier up to 10,000 RPM/30M TPM at the top tier — Source: requesty.ai "LLM API Rate Limits 2026" and similar secondary aggregator posts, n.d. (2026), accessed 2026-10-28, confidence: low-medium (not fetched from OpenAI's own rate-limits page directly), class: rate limits
